# Security

## Reporting a vulnerability

Report a suspected vulnerability privately through GitHub security advisories:
open the Security tab of
[github.com/thingctx/thingagent](https://github.com/thingctx/thingagent/security/advisories/new)
and choose "Report a vulnerability". Do not open a public issue. We aim to answer
within a few business days.

## What thingagent does not protect against

Read the [Limits](README.md#limits) section of the README and
[docs/LIMITS.md](docs/LIMITS.md) first. They list what thingagent does not defend
today, such as a broker that does not bind each login to its name and a policy
check that shares a process with the model when no broker is used. A report about
one of those limits is still welcome when it shows a way around the stated defense.
